Platform Architecture & Specifications

Key engineering specifications & subsystems:

  • Frontend: Clean semantic HTML5, pure CSS3 responsive layout, minimal JS for charts and alerts.
  • Backend: Python 3 with Flask, Werkzeug password hashing (scrypt).
  • Database: SQLite3 with parameterized SQL queries, relational constraints, foreign keys, and indexes.
  • Algorithms: Linear Search, Binary Search $O(\log n)$, QuickSort $O(n \log n)$, MergeSort, Hash Index $O(1)$, Max-Heap Priority Queue.
  • APIs: Alpha Vantage, GoldAPI, NewsAPI, and MFAPI with automatic SQLite caching and resilient offline fallbacks.

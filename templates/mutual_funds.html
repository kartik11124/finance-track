About MFAPI.in

MFAPI is a community-maintained open REST API offering daily updated Net Asset Value (NAV) records for all AMFI-registered mutual fund schemes across India.

  • Requires ZERO API keys or authentication tokens.
  • Covers all open-ended equity, debt, and hybrid mutual fund houses (HDFC, SBI, ICICI, Parag Parikh, Nippon, Axis, Mirae).
  • Provides instant real historical NAV data points.
